# The-Odin-Project--Calculator
A functional calculator built with HTML, CSS, and JavaScript, featuring basic arithmetic operations and an interactive user interface.


## About the Project

This project is a browser-based calculator that allows users to perform basic arithmetic operations through an interactive interface.

The project focuses on applying JavaScript fundamentals to a practical project while using DOM manipulation and event handling to make the calculator interactive.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Clear/reset functionality
* Interactive calculator buttons
* Displays calculations and results directly on the page

## Technologies Used

* HTML5
* CSS3
* JavaScript
